# Security policy

hoardDB holds people's data, so a vulnerability report is the most useful thing a
stranger can send us. Please send it privately.

**Do not open a public issue, discussion or pull request for a security problem.**

Report it with GitHub's private vulnerability reporting (the "Report a vulnerability"
button under the Security tab of the repository the problem is in), or by email to
**admin@hoarddb.com**.

Please include what you found, the version it affects (`hoarddb-server -v` prints it),
steps to reproduce it, and what an attacker gains. You do not need an account, a form
or an agreement to be heard.

We acknowledge a report within 3 working days, tell you what we found within 10 working
days, and agree a disclosure date with you no later than 90 days after the report (sooner
for a problem that is being exploited).
